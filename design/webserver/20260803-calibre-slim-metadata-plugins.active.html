TALEBOOK · ISSUE #907

在 slim runtime 恢复 Google / Amazon 元数据源

创建日期2026-08-03
所属模块webserver
状态ACTIVE
需求来源GitHub #907

根因

slim 基础镜像使用 calibre.customize.standalone_builtins，该列表只保留转换和文件元数据插件，没有注册 Google 与 Amazon.com。源码模块仍在镜像中，因此查询不会报 import 错误，却因 identify 注册表为空而静默返回零结果。

修复链路

1 · 检查
首次查询读取 identify 注册表。
2 · 恢复
仅对缺失项导入官方插件类，调用 Calibre 初始化器并加入运行时注册表。
3 · 诊断
恢复失败时抛出含插件名的明确异常，不再伪装为无结果。

边界与兼容性

注册过程加锁且幂等；完整 Calibre runtime 已存在插件时不重复添加；仍使用 Calibre 原生 identify 聚合、超时、评分及封面缓存逻辑。该兼容层只恢复 Talebook 已允许的 Google 与 Amazon.com。

测试结果

pytest tests/test_calibre_metadata_runtime.py -q：3 项通过，覆盖空注册表恢复、幂等和明确诊断异常；相关文件通过 ruff check 与 ruff format --check。当前环境无 Docker daemon，production slim 镜像实测交由 PR GitHub Actions；主要风险是 Calibre 后续改变私有注册表结构，失败时会输出具体插件名而非静默空结果。
